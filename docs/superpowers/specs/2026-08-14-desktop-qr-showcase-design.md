# Desktop QR Showcase Design

## Goal

在桌面宽屏演示时保留现有居中的 390×844 手机模拟器，并利用左右空白区域展示两个等尺寸二维码入口：左侧“网站”，右侧“体验群”。窄屏和真实手机继续只显示产品界面。

## Approved approach

- 复用 `PhoneFrame` 作为唯一演示外壳入口，在 `.pixel-stage` 内增加两个语义化的二维码卡片。
- 左侧使用用户提供的网站二维码，通过纯 CSS 视窗裁掉源图自带文字，再统一由组件渲染“网站”标签。
- 右侧使用用户提供的体验群二维码，使用同一二维码视窗尺寸并渲染“体验群”标签。
- 仅在视口宽度至少 1180px、浏览器显示模式下展示；更窄视口不改变现有手机和移动端布局。
- 二维码图片随 H5 构建发布，不依赖外链或运行时生成，不增加依赖。

## Visual contract

- 两侧卡片宽度、二维码可视区域、标题字体、圆角、阴影一致。
- 卡片围绕手机水平对称，手机仍是视觉中心。
- 二维码保持高对比白底与足够留白，不能被圆角、阴影或装饰覆盖。
- 桌面高度不足时允许页面按现有手机框架策略适配；二维码卡片始终不遮挡手机。

## Verification

- 组件测试锁定两张二维码及“网站 / 体验群”标签。
- H5 全量单元测试、typecheck、生产构建通过。
- 390×844 截图确认移动端无二维码侧栏。
- 2048×1270 截图确认左右卡片等尺寸且不遮挡手机；二维码扫码可识别。
- 部署后验证公网首页、健康接口和桌面/移动关键路径。
