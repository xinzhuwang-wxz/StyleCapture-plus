## 改了什么

范围是**令牌与字体**，没有动任何类名、DOM 或可见文案，所以 228 个既有测试
一个都没被打破。

| 令牌 | 原值 | 新值 | 依据 |
|---|---|---|---|
| `--pixel-primary` | `#7c3aed` | `#8b5cf6` | 设计稿 44 处，用于文字/描边/阴影 |
| `--pixel-primary-fill` | 无 | `#a78bfa` | 设计稿实心底 16 处，比描边浅一档 |
| `--pixel-text-muted` | `#66528e` | `#7c6aa8` | 设计稿正文次级，34 处 |
| `--pixel-text-dim` | `#7d6aa5` | `#a89cc9` | 设计稿说明文字，34 处 |
| `--pixel-shadow` | `rgba(139,92,246,.10)` | `#ece5f8` | 设计稿 23 处用的是实色淡紫 |
| `--font-pixel` | `= --font-body` | `"ZCOOL KuaiLe", …` | 设计稿 152 处 |

阴影从半透明改成实色是有理由的：半透明会把下层颜色吃进来，卡片叠卡片时
越叠越脏；实色淡紫叠多少层都干净。

`--font-pixel` 原本只是 `--font-body` 的别名，而它已经在 25 处标题、按钮、
徽章上用着了——正好是设计稿用圆体的那些位置。改这一个变量就全局生效。

## 刻意偏离设计稿的一处

底部导航未选中态**没有**用设计稿的 `#a89cc9`，用的是深一档的 `#7c6aa8`。

`#a89cc9` 对白底实测 **2.54:1**，而导航标签是 11px 的功能性文字，
WCAG AA 要求 4.5:1。`#7c6aa8` 是 **4.68:1**，通过。
认不出自己在哪一屏，比不够还原严重得多。

装饰性小标题（`.pixel-label` 那类带字距的 kicker）仍用 `#a89cc9`，
与设计稿一致——它们旁边都有承载同样信息的大标题。

## 已知限制

`fonts.googleapis.com` 在中国大陆访问不到。届时 `--font-pixel` 会整条回落到
系统字体，版式不变，只是不圆——**不会错版**，但现场演示如果走大陆网络，
看到的不是这些截图里的样子。要在大陆保真，得自托管字体子集，那是另一件事。
