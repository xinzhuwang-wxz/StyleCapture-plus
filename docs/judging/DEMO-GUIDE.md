H5 会自动创建匿名体验会话，并预置一组已经标明 `curated_seed` 来源的真实单品、像素封面与穿搭，评委无需注册即可直接体验。

## 建议的 3 分钟体验路径

1. **Feed 圈选入库**
   - 首屏就是灵感 Feed。
   - 点击画面暂停或右下角“圈选”，沿衣服画圈。
   - 选择“存单品”或“存整套”；左划取消，右划加入数字衣橱。
   - 后台会调用真实视觉理解与搭配分析，页面可继续浏览，完成后自动更新。
2. **数字衣橱**
   - 点击底部“数字衣橱”。
   - 一级卡片使用像素封面；点开后查看真实单品图、分类、标签、来源和穿搭关系。
   - “按穿搭 / 按单品”可切换，预置资产排在前面，新入库内容追加其后。
3. **Try 像素形象**
   - 点击底部中央“+”，选择“试试像素形象”。
   - 上传或拍摄全身照；生成过程在后台继续，离开页面不会丢任务。
   - 结果可保存或删除；Try 默认不写入衣橱。
4. **AI 搭配与真人试穿**
   - 进入“AI”，用中文描述场景，例如“周五面试，简洁正式但不要太沉闷”。
   - 搭配方案逐套返回，不等待全部完成；保存喜欢的方案即可形成穿搭资产。
   - 在穿搭详情选择“真人试穿”，上传正面全身照，生成该套穿搭的试穿效果。
5. **上传真实衣服**
   - 点击底部中央“+”，选择相机或相册。
   - 支持 JPG、PNG、WebP、HEIC/HEIF；识别、单品化、标签和像素封面均异步完成。
   - 可删除原始上传图，保留提取后的单品图、结构化标签和数字资产。

## Skill / API 交付

`skills/scene-outfit-matching` 是搭配推荐 Skill 的薄封装，复用 H5 相同的 Product API、会话、真实衣橱数据和 LiteLLM 能力，不包含固定推荐结果。

```bash
cd skills/scene-outfit-matching
npm test
STYLECAPTURE_API_URL=https://119.45.216.38 \
node scripts/match.js --request '{"scene":"周五面试","style":"简洁正式"}'
```

API 端点、请求结构与响应结构以 OpenAPI 为准。所有运行时模型请求均通过服务端 LiteLLM 能力别名路由，浏览器端不持有模型密钥或供应商配置。

## 已完成的公网实测

- 五个一级入口、Feed 与衣橱同尺寸手机画布、往返导航。
- Feed 暂停/恢复、圈选引导、微小圈选拦截、左划取消、右划整套入库并自动完成分析。
- Try 像素形象真实上传、生成、删除，且不污染数字衣橱。
- 中文 AI 需求、渐进式多套搭配、保存穿搭、真实全身照试穿、失败恢复。
- 真实衣服上传、后台理解、详情与标签、刷新持久化；原图删除与数字资产保留由 API 集成测试覆盖。
- PostgreSQL、Redis、LiteLLM 就绪检查；HTTPS、安全头、成本/并发护栏、备份恢复和 30 Mbps 公网性能。

生成式能力通常需要几十秒；Seedream 暂时繁忙时任务会自动重试。系统不会用 mock 或固定图片冒充本次生成结果。
